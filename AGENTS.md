# Agent Entry Surface

This repository contains **Semantic System Design (SSD)** as both a book and an architectural discipline that can be applied by agents.

The root `README.md` is the general repository and book entry surface. This file is the agent-specific entry surface.

## Working with SSD

When asked to apply SSD to an unfamiliar system-design problem, use the [SSD architectural skill](skills/ssd/SKILL.md).

Use the repository source material to ground the reconstruction. Preserve source traceability, distinguish source-backed claims from transferred conclusions, expose source gaps explicitly, and avoid inventing SSD doctrine when the source does not support it.

The skill is an operationalization of SSD, not a replacement definition of SSD or a separate agent-facing version of the discipline.
